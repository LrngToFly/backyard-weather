# Backyard Weather

A personal iPhone web app that shows live readings from a Weather Underground backyard weather station next to Euro (ECMWF) forecast maps for New England. Currently set up for a station in Hopkinton, MA.

- Station data: Weather Underground personal weather station API (your own free API key, stored only on your phone).
- Model data: [Open-Meteo](https://open-meteo.com/) ECMWF IFS open data (CC BY 4.0).
- Runs entirely in the browser. No server. Add it to the iPhone Home Screen from Safari.

Not for safety-critical decisions.
